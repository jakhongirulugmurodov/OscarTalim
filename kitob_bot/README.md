# Китоб дўкони — Телеграм бот

Фақат Python'нинг стандарт кутубхонаси ишлатилган, қўшимча ҳеч нарса ўрнатиш шарт эмас.

## Мижоз нима кўради

1. **Рўйхатдан ўтиш** — `/start` босилганда бот исм-фамилия, телефон рақам
   (тугма орқали) ва яхши кўрган жанрларни сўрайди. Рўйхатдан ўтгани учун
   мижозга совға берилади (`xush_kelibsiz_sovga`).
2. **Сўровнома** — 5 та савол (`dokon.json` → `sorovnoma`). Натижаларни `/stat` кўрсатади.
3. **🔎 Китоб излаш** — китоб номи ёки муаллифини кирилл ёки лотинда ёзса бўлади
   (`otgan kunlar` ҳам «Ўтган кунлар»ни топади). Тугма босмасдан ёзилган ҳар қандай
   матн ҳам қидирув ҳисобланади.
   - бор бўлса — «Бор!», нархи, чегирмаси, омборда нечта борлиги;
   - йўқ бўлса — кейинги ҳафта қайси китоблар келиши ва **«🔔 Келганда хабар беринг»**
     тугмаси. Китоб келганда (`/kitob` ёки `/soni` билан) мижозга ўзи хабар кетади.
4. **🆕 Янги китоблар**, **🏷 Чегирмалар**, **📅 Кейинги ҳафта**.
5. **🎉 Жума акциялари** — ҳар жума 09:00 да (Тошкент) бот ҳамма мижозга акциядаги
   китоблар рўйхатини юборади.
6. **🎁 Совғаларим** — мижознинг ишлатилмаган совғалари ва кодлари.
7. **🏪 Дўкон ҳақида** — манзил, иш вақти, телефон, Инстаграм, харита.

## Дўкон эгаси нима қилади

Ботда `/admin` — барча буйруқлар рўйхати. Энг кўп ишлатиладиганлари:

| Буйруқ | Нима қилади |
|---|---|
| `/xarid +998901234567 \| Ўтган кунлар` | Харидни ёзади: мижозга **«Сиз совғага эга бўлдингиз»** хабари кетади, омбордан 1 дона айрилади. Ҳар 5-харидда катта совға. |
| `/sovga +998901234567 \| Бепул кофе` | Махсус совға юбориш |
| `/kod KBXXXXX` | Кассада: мижоз айтган совға кодини текшириш ва «ишлатилди» деб белгилаш |
| `/kitob Ном \| Муаллиф \| Жанр \| Нарх \| Сони` | Китоб қўшиш/янгилаш. Янги китобга шу жанр мухлислари ва кутаётганларга хабар кетади |
| `/soni Ном \| 5` | Омбордаги сонни ўзгартириш |
| `/chegirma Ном \| 20` | 20% чегирма — шу жанрни яхши кўрадиганларга хабар кетади |
| `/juma Ном \| 30` | Жума акциясига қўшиш (`/juma_tozala` — тозалаш, `/juma_yubor` — ҳозир юбориш) |
| `/keladi Ном \| Муаллиф \| Жанр \| Қачон` | Кейинги ҳафта келадиган китоб (`/keladi_tozala`) |
| `/xabar Матн` | Ҳамма мижозга хабар |
| `/stat` | Мижозлар сони, жанрлар ва сўровнома натижалари |

Жанр номи `dokon.json` → `janrlar` рўйхатидаги билан бир хил ёзилиши керак —
шунда янги китоб ва чегирма хабари тўғри мухлисларга боради.

## `dokon.json`

Дўкон номи, манзили, телефони, харита координаталари (`lat`, `lon`), жанрлар,
сўровнома саволлари, совғалар рўйхати ва бошланғич каталог шу файлда.
Ҳозир у ерда **намуна маълумотлар** турибди («Китоб олами», манзил, телефон ва ҳ.к.) —
уларни истаган вақт ўзгартиришингиз мумкин. Ўзгариш ботнинг кейинги ишга тушишида
(1 соат ичида) кучга киради.

Каталог ҳақида:
- `dokon.json` га янги китоб қўшсангиз — у ботга ҳам қўшилади;
- мавжуд китобнинг нархи ва сонини эса ботнинг ўзида ўзгартиринг:
  `/kitob`, `/soni` (бот ўз каталогини ўзи юритади, файлдаги нарх фақат биринчи марта олинади);
- кейинги ҳафта рўйхати ботда `/keladi` ва `/keladi_tozala` билан бошқарилади.

## Ишга тушириш

1. Телеграмда [@BotFather](https://t.me/BotFather) → `/newbot` → токенни оласиз.
2. Ботга ёзиб `/men` юборинг — Телеграм ID'ингизни билиб оласиз
   (бу ID дўкон эгаси сифатида киритилади).
3. **GitHub'да (сервер керак эмас):** Settings → Secrets and variables → Actions:
   - secret `KITOB_BOT_TOKEN` — токен;
   - variable `KITOB_ADMIN_IDS` — ID'лар вергул билан (масалан, `123456,789012`).

   Кейин Actions → «Kitob do'koni bot» → Run workflow → `sozlash`.
   Бот ҳар сафар 50 дақиқа узлуксиз ишлайди ва хабарларга дарҳол жавоб беради, кейин
   навбатдагиси бошланади (жадвал фақат `main` шохчасида ишлайди). Actions рўйхатида
   «cancelled» бўлиб қолган ишга тушишлар — навбатда кутиб турганлар, бу нормал ҳол.
4. **Ўз серверингизда (жавоб дарҳол келади):**

   ```bash
   BOT_TOKEN=... ADMIN_IDS=123456 python3 kitob_bot/bot.py
   ```

   Жума акцияси учун cron: `0 9 * * 5 BOT_TOKEN=... python3 kitob_bot/bot.py --juma`
